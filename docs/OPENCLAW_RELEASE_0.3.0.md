## Autonomous paper strategies and private position plans

The integrated path is dated public source evidence → exact-pool closed hourly OHLCV → deterministic EMA12/26, Wilder RSI14/ATR14 and closed-bar volume acceleration → bounded strategy entry → paper fill → staged exits/stop/rotation → cost accounting and prospective outcome review. Current execution-price extension is checked separately against the closed-bar reference, including when research is cached. No incomplete candles, missing hours, backfilled baselines or model-generated indicators are used. Sixty continuous closed hourly bars are required; this is hourly research with sampled minute monitoring, not an intraminute scalper.

The existing shared Paper Trader now supports an explicit operator-started autonomous strategy mode. It runs while the app server runs even after the page closes. Start/Pause/Reset require a signed holder session whose wallet matches the existing configured `AXO_ADMIN_WALLET`; same-origin alone is insufficient. Public visitors can read public paper results. The older Luna-governed mode remains separate and retains its shared model budget/presence requirements. Strategy mode uses deterministic decisions and no model call per trade.

Momentum continuation requires aligned trend, bounded RSI/current extension/runup, genuine bar-volume acceleration and measured hourly buy/sell participation. Rebound entries require the existing development-backed rebound qualification for the same exact token/pool. Rotation closes a weakening position before reconsidering another eligible setup on a later cycle. All entries require fresh screening, actual reported circulating market cap (never FDV), liquidity and a dated exact-pool buy/sell simulation. Missing or unsupported simulation coverage produces a pass/unknown state; the current adapter supports Ethereum, Base and BNB Chain, not every chain/pool type.

Experimental editable defaults: actual MC $100k–$25m, pool liquidity ≥$100k, current EMA extension ≤12%, 24h runup ≤300%, closed-bar volume acceleration ≥1.3×, fixed stop 8%, trailing stop 12%, staged targets 10/25/50% with 25% of original quantity at each, and a remaining 25% runner. These are unvalidated research parameters, not recommended entries or a profit forecast. Existing portfolio allocation, cash reserve, max-position and pool-participation safeguards remain; new entries are capped at five per rolling day by default. Global configuration changes apply to future paper entries and preserve attached plans, completed tranches and high water. Stops take precedence; any modeled exit uses the observed price with adverse slippage, fees and known provider taxes, not a guaranteed stop price. Failed/missing routes do not become fills; pending exits retry only on bounded cycles with still-fresh matching observations.

Net recovery counts only realized exit proceeds after modeled costs against actual recorded original outlay, never the marked value of remaining tokens. Full closes explicitly remove floating-point dust and free the position slot. The journal records strategy version, parameter assumptions, observations, decisions, passes, failures and partial fills prospectively. Daily cards include realized/unrealized P&L, exposure, fees, failed exits, no-trade days and an extra-50bps-per-fill cost sensitivity. These are forward paper observations; no historical backtest or daily-profit guarantee is claimed, and paper gains do not imply linear scalability to real capital. Gas, MEV and executable user-size routing are not modeled.

Memory retains only 200 recent decisions, 200 recent fills, 240 chart marks and 31 daily aggregates. All-run peak/drawdown/counters and rolling-day entry timestamps are incremental; replay streams the append-only journal. Prior run records are retained across explicit reset. The operator must monitor disk usage and archive old completed runs with a verified checkpoint/replay procedure; do not truncate the active hash chain or delete history to fix a load error.

Project pages expose technical evidence and editable position-plan previews. The score's labeled 15-point entry-suitability component now uses exact dated technical evidence and the current-price guard; missing history earns no points. The remaining 85 points describe project/evidence quality. The total remains an uncalibrated research score, not probability of profit.

Intentionally imported positions live under `private/position-plans.json`, isolated by signed wallet, and appear in Portfolio and the existing signal inbox. Quantities, entry price/outlay and exit receipts are explicitly user reported, not independently chain-verified. Missing cost basis or exit fees leave P&L/recovery unknown. Receipt IDs deduplicate, oversells are rejected, remaining quantities persist, and stale/missing exact-pool observations produce coverage-paused states. These live-position controls only monitor, alert and open the existing reviewed swap panel. They never sell, sign, transmit a swap, install a trading key or guarantee an exchange stop order. Owner changes immediately clear private UI content; workspace deletion removes private monitor records.
